# payments

Учебный платёжный модуль на Go. Демонстрирует работу с структурами,
интерфейсами, методами, тестами и ошибками в контексте системы платежей.

## Что умеет

- Поддержка нескольких валют: RUB, BYN, KZT, CNY, EUR, USD, BTC
- Формирование чека после оплаты
- Несколько способов оплаты через единый интерфейс

## Требования

- Go 1.21 или выше

## Запуск

    go run ./cmd/payments

## Структура

- `cmd/payments` — точка входа
- `internal/domain` — доменные типы: валюты, суммы
- `internal/receipt` — формирование чека
- `internal/payment` — способы оплаты
